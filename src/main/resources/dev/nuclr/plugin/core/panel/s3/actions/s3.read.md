# s3.read — Read an object

Downloads the start of an object and returns it: as text when it is valid UTF-8,
as base64 otherwise (`encoding` says which).

- At most `maxBytes` are returned (256 KB by default, 4 MB at most). `truncated`
  says when the object is longer; `size` is its full length. Check `size` with
  `s3.head` first for objects that may be large.
- Compressed objects (`.gz`, `.zip`, …) come back as base64 of the compressed bytes.
- To move an object somewhere else, use `s3.copy` instead of reading and writing
  it: the content then never passes through you.
