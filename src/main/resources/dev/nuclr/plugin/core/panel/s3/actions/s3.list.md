# s3.list — List objects in a bucket

Lists one page of keys under a prefix.

- S3 has no real folders: keys are full paths such as `logs/2026/10/app.log`. By
  default the listing groups deeper keys into `folder` entries (keys ending in `/`),
  like a file browser. List a folder by passing its key as the next `prefix`.
- `recursive: true` lists every object below the prefix instead, with no folder
  entries — the way to find files deep in a tree.
- A prefix is matched literally from the start of the key: `logs/2026` also matches
  `logs/2026-old/…`. End it with `/` to mean a folder.
- At most `limit` entries per page (1000, S3's own maximum). When `truncated` is
  true, call again with `continuationToken` set to `nextContinuationToken`.
- Without `bucket`, a profile tied to a bucket lists that bucket, starting at its
  own prefix.

Example: `{ "profile": "prod-assets", "bucket": "nuclr-logs", "prefix": "web/2026/10/" }`
