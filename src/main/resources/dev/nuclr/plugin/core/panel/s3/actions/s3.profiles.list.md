# s3.profiles.list — List saved S3 profiles

Lists the S3 connection profiles the user has saved in Commander's S3 panel. Call it
first: every other `s3.*` action names its profile by the `id` or `name` returned
here.

- Only saved profiles can be used. To reach a new account or endpoint, ask the user
  to add a profile in the S3 panel.
- A profile may be tied to one bucket (and prefix). For such a profile, `bucket`
  can be left out of the other actions and means that bucket.
- `endpoint` is set for S3-compatible services (MinIO, Cloudflare R2, Wasabi, ...);
  `null` means AWS itself.
- Credentials are resolved on first use. If a secret is needed and not stored,
  **the user** is asked in Commander — never you. Access keys, secrets and session
  tokens are never returned.
