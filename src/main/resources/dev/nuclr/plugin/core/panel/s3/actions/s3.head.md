# s3.head — Get an object's details

Returns an object's size, last modification time, storage class and ETag without
downloading any of it. Use it to check an object exists, or how large it is before
reading it.

- `key` is the full key inside the bucket, e.g. `reports/2026/q3.csv`; a leading
  `/` is ignored.
- A key that does not exist fails with a message saying so. Folders (keys ending in
  `/`) usually have no object of their own; use `s3.list` for them.
