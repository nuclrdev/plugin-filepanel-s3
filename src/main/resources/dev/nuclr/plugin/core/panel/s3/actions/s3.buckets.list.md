# s3.buckets.list — List buckets

Lists the buckets a profile's credentials can see.

- Credentials made for a single bucket often may not list buckets at all. For a
  profile tied to a bucket, the result then holds just that bucket and a `note`
  says so; for any other profile the call fails with "Access denied" — ask the user
  which bucket to use.
- `region` is filled in when S3 reports it. You never need it: requests find each
  bucket's region by themselves.
