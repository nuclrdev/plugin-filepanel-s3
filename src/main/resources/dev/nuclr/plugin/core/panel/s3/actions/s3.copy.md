# s3.copy — Copy an object

Copies one object, possibly to another bucket, profile, account or S3-compatible
endpoint. The content goes from S3 to S3 through Commander and never through you,
so this is the way to move data, secrets included, without reading it.

- Within one profile S3 copies the object itself (`serverSide: true`) for objects
  up to 5 GB. Between profiles, or for larger objects, Commander downloads
  it to a temporary file and uploads it; the target is untouched until the upload.
- An existing object at `toKey` is never replaced silently: without
  `overwrite: true` the call fails and nothing is copied; with it, the user is asked
  to approve.
- One object per call. To copy a folder, list it with `s3.list` and
  `recursive: true`, then copy each key.
- Defaults: `toProfile` is `fromProfile`; `toBucket` is `toProfile`'s own bucket
  when it has one, else `fromBucket`.

Example: `{ "fromProfile": "prod", "fromBucket": "nuclr-backups", "fromKey": "db/2026-10-03.sql.gz", "toProfile": "archive", "toBucket": "cold-archive", "toKey": "db/2026-10-03.sql.gz" }`
