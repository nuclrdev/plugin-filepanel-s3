# s3.write — Write an object

Creates an object with the given content, or replaces an existing one entirely.
S3 has no partial writes: `content` is always the whole object.

- Replacing an existing object asks **the user** to approve it, showing a unified
  diff when old and new are both text under 1 MB. Declined means nothing was
  written. Writing exactly the content already there writes nothing and returns
  `unchanged: true`.
- Unless the bucket has versioning on, a replaced object's old content is gone.
- Use `encoding: "base64"` for binary content.
- The key must not end in `/` (that is how S3 tools mark folders). Folders need not
  exist first: writing `a/b/c.txt` is enough for `a/` and `a/b/` to appear.
- The content type is chosen from the key's extension.

Example: `{ "profile": "prod-assets", "bucket": "nuclr-config", "key": "web/feature-flags.json", "content": "{\"beta\": true}\n" }`
